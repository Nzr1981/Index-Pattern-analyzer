INDEX GAME ANALYZER – DAY 2

Core Prediction Engine (Candidate Generation)

Continue the existing project without removing or changing any working functionality from Day 1.

The objective of this stage is to build the Prediction Generation Engine. This engine must generate every possible predicted Close Number using historical market data. Do NOT implement AI learning, confidence scoring, or ranking in this stage.

---

Primary Objective

The prediction engine must generate candidate Close Numbers using all available historical relationships before any ranking or filtering occurs.

Every generated candidate must be stored with complete information about how and why it was generated.

---

Data Sources

Generate predictions using:

- Today's Open

- Previous Week
- Daily Data
- Weekly Data
- Taiwan
- Kospi
- Hang Seng
- Sensex
- DAX
- Dow Jones

Every index must be analyzed independently and together.

Opposite Number Engine

Generate opposite digits using:

1 ↔ 6

2 ↔ 7

3 ↔ 8

4 ↔ 9

5 ↔ 0

18

18

68

13
